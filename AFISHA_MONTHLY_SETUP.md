# Автоматическое ежемесячное обновление афиши (TimePad, все 12 городов)

Разовая настройка на твоём Mac (~10 минут). После неё сбор данных, коммит и
пуш в git будут происходить сами, раз в месяц, без твоего участия — с
уведомлением в Telegram по итогу (успех или ошибка).

## 1. Секреты (один раз)

Создай файл с токенами — он НЕ попадает в git (только у тебя на диске):

```bash
mkdir -p ~/.taxi-bot-secrets
cat > ~/.taxi-bot-secrets/afisha_monthly.env << 'EOF'
TIMEPAD_TOKEN="твой_токен_с_dev.timepad.ru"
BOT_TOKEN="токен_бота_из_@BotFather"
ADMIN_TELEGRAM_ID="147611511"
EOF
chmod 600 ~/.taxi-bot-secrets/afisha_monthly.env
```

`TIMEPAD_TOKEN` — тот же, что ты уже используешь для ручных запусков.
`BOT_TOKEN`/`ADMIN_TELEGRAM_ID` — нужны только для уведомлений в Telegram,
можно оставить пустыми (`""`), тогда просто не будет пуша, всё остальное
отработает как обычно.

## 2. Файлы скрипта

Два файла из этой пересылки (`run_monthly_afisha_update.sh`,
`com.taxihelper.timepad-monthly.plist`) должны лежать РЯДОМ с `main.py` —
то есть в `~/Desktop/taxi-bot-deploy/`. Сделай скрипт исполняемым:

```bash
chmod +x ~/Desktop/taxi-bot-deploy/run_monthly_afisha_update.sh
```

## 3. Установка launchd-задачи (один раз)

```bash
# Подставить реальный путь вместо плейсхолдера в plist:
sed -i '' "s|REPO_DIR_PLACEHOLDER|$HOME/Desktop/taxi-bot-deploy|g" ~/Desktop/taxi-bot-deploy/com.taxihelper.timepad-monthly.plist

# Скопировать в LaunchAgents и загрузить:
cp ~/Desktop/taxi-bot-deploy/com.taxihelper.timepad-monthly.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.taxihelper.timepad-monthly.plist
```

Готово — с этого момента задача будет запускаться сама 1-го числа каждого
месяца в 09:00. Если в этот момент Mac спал или был выключен — launchd
досрочно выполнит пропущенный запуск, как только компьютер снова станет
доступен.

## 4. Проверить, что всё работает (сразу, не дожидаясь 1-го числа)

```bash
launchctl start com.taxihelper.timepad-monthly
```

Через 10-30 секунд проверь лог:

```bash
tail -50 ~/Library/Logs/taxi-bot-afisha-monthly.log
```

Должно быть видно: сбор по всем 12 городам, коммит, пуш, и в Telegram
должно прийти сообщение с итогом (если задал `BOT_TOKEN`/`ADMIN_TELEGRAM_ID`).

## Что уведомление означает

- ✅ — всё прошло, данные обновлены и запушены, Railway задеплоит сам.
- ℹ️ — сбор прошёл, но данные не изменились (файл идентичен прошлому разу) — коммита не было, это нормально.
- ❌ — что-то не получилось (нет сети, токен истёк, конфликт в git и т.п.) — в сообщении и в логе будет видно, на каком шаге. В этом случае просто исправь причину и один раз запусти `launchctl start com.taxihelper.timepad-monthly` вручную — дальше опять пойдёт само.

## Как остановить/отключить

```bash
launchctl unload ~/Library/LaunchAgents/com.taxihelper.timepad-monthly.plist
```

(файл `.plist` при этом остаётся — `launchctl load` снова включит по тому
же расписанию).

## Про источник данных (важно)

Это обновляет только TimePad-афишу (реальный API, легально) — все 12
городов бота теперь участвуют в ежемесячном сборе (раньше 4 города были
исключены как "почти нет событий", но раз сбор теперь фоновый и
ежемесячный — экономить уже незачем, просто может честно приходить 0
событий в отдельных городах отдельные месяцы).

Яндекс.Афиша сюда сознательно НЕ подключена: у неё нет публичного API на
чтение списка мероприятий (их API — только для партнёров, которые сами
загружают СВОИ события на продажу), получить данные оттуда можно только
скрейпингом сайта — без официальной поддержки, с риском блокировки
(Яндекс жёстче TimePad/Cloudflare) и нарушением условий использования
сайта. Если всё же понадобится — дай знать явно, соберу отдельным
экспериментальным источником с пометкой о рисках.
